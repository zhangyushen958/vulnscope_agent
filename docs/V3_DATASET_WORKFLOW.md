# V3 数据输入与结果评分审查记录

## 数据来源

此次交付包含用户上传的 `dataset.zip` 中 `knowledge.jsonl`、`test.jsonl`、`evaluation.py`。不会在运行时联网下载课程知识。原数据条数：7,578 条知识记录，300 条测试记录。

## 关键改动

- 新增 `app/course_io.py`：安全读取本地固定文件名、文件大小限制、输入严格校验、原子写文件及评分封装。
- 新增 `app/scoring.py`：沿用课程相邻成对算法，P-C、P-V、P-B、P-R 和等级惩罚。
- `app/web.py` 新增本地知识库/批量任务入口、历史任务列表和评分接口。
- `app/service.py`：提交任务时记录数据指纹、模型仍按样本独立推理；检测结束后持久化结果。仅评分时读取真值且确认输入指纹一致。
- 前端新增「检测评分」视图、默认本地数据入口和统计可视化；文件上传可选。
- `scripts/start.sh` 统一使用 `python -m uvicorn` 避免环境路径错误。
- `dataset/` 包含直接可用的课程数据，`result/` 自动创建。

## 工程验证

- Python 回归测试：80 项通过（含 12 项 V3 数据路径、持久化、评分和隔离测试）。
- 真实知识库全量读取：导入 3,769 个独立配对，17 个配对不一致、3 个重复对被排除。
- 真实测试文件格式校验：300 条通过。
- 评分算法：测试了四种配对类别、部分结果、过早评分拒绝、测试数据修改后拒绝评分。
- V3 不会在缺少 API Key 时捏造预测，也不会将 300 条测试集的真值直接提供给 Agent。
